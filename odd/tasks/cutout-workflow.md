# Cutout workflow

Rework the Extruded Cutout command: always available, guided face -> sketch -> cutout flow with the face outline projected, a One wall depth, and a clearer icon and name.
Branch: `feat/cutout-workflow` (from `main` 4f602ba). Native runner: `python3 ci/run_tests.py --freecad-bin .git/ci-policy-runtime/squashfs-root/AppRun --reports <dir> --timeout 1500 [--test <module>]`. Format: `.git/format-tools-homebrew-venv/bin/{black,isort}`.

## Specs

- S1. "Boton siempre activo." The Extruded Cutout command is active whenever a document is open, whatever the selection. Its panel explains every selected item it cannot use (not a planar face of a profile, trim or cutout; a thickness/edge pick; more than one face), as Notch and Extend / Cut panels do.
- S2. "Al hace click, pida seleccionar una cara -> crear sketch -> generar el corte." Clicking the command opens a panel asking for one planar face of a profile, a trimmed profile or an existing cutout (picked in the 3D view, or preselected). OK creates, in one Undo step: a sketch inside the same container (App::Part / group) as the picked object, attached to that face (Map Mode FlatFace), and the cutout object linked to that face and sketch; then it opens the sketch for editing. Closing the sketch recomputes the cutout. A cutout whose sketch is empty (or has no closed wire) shows the base shape uncut, without an error. Cancel leaves the document unchanged. The existing path stays: with one face and one sketch preselected the command creates the cutout directly from them (and moves the sketch into the picked object's container, as today).
- S3. "Cambiar el icono por algo mas intuitivo, quizas un tubo son un calado". New icon: a rectangular tube with a round hole and a slot cut through its wall, in the style of `corner-end-miter.svg` / `corner-notch.svg`. The command is renamed in the UI to "Cutout / Hole" (Spanish "Calado"); the command ID `MaxProFrame_AddExtrudeCutout` and the object type stay. Spanish entries in both catalogs.
- S4. Depth "One wall" (Spanish "Una pared") as a third `CutType` choice next to Through All and Distance: it cuts only the wall under the picked face, never the opposite wall of a tube (example: a hole sketched on the top face of a TC80x40x1.5 tube goes through the top wall and leaves the bottom wall intact). The guided flow (S2) creates cutouts with One wall by default; the Through All default of the direct path is kept.
- S5. "sumemos la proyeccion". When the command creates the sketch (S2), the outline edges of the picked face are added to it as external geometry (construction), so the user can dimension the hole against the face edges right away without using External Geometry.
- S6. Docs: tutorial section "Cutout / Drill" rewritten for the new flow, tooltip/help text updated, CHANGELOG Unreleased entry.
