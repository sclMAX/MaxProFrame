One pencil opens properties, with an optional modeless Sketcher editing session. Branch: `feat/unified-custom-profile-editor`; baseline: `0517ca6`.

## Specs
S1. User: "Si usamos el lapiz para abrir el modal actual con los campos y agregamos una opcion editar seccion, si se usa esta opcion recien entonces ocultamos la biblioteca, abrimos el sketch y mostramos la ventana de editar perfil ? que opinas?" Approved path: pencil opens the properties modal; only Edit Section transitions to native Sketcher plus a modeless Edit Profile window, preserving pending field values and stable profile identity. Properties-only acceptance does not open geometry. Remove separate Edit Section/Apply Section Edit toolbar actions from the visible manager. Use Accept rather than Save in the properties modal; library Save Changes remains publication.
S2. User: "- Si aprieto cancelar o cierro el croquis, cancelamos la edicion.\n- Si aprieto ok, confirmamos los cambios y habilitamos el boton guardar.\nen ambos casos cerramos el sketch." Accepted session semantics: OK validates properties and geometry, stages the complete accepted edit, closes the working copy and returns to the manager. Invalid input stays editable without partial staging. Cancel/closing discards the whole current session, including fields edited before entering Sketcher, preserving earlier library changes. Native sketch closure never implies acceptance; confirmation may protect modified work. Geometry acceptance retains the existing recalculation of manual weight. Original asset is not modified before library publication; geometry stays unavailable for missing/unusable assets without blocking properties-only editing.
S3. User: "OK vamos con eso, recuerda que damos soporte a la estable y a la rc debeos probar en ambas". Run deterministic public GUI tests and the full native suite on both FreeCAD 1.1.4 and 26.3rc2. Preserve permissions, metadata, selection targeting and standard-family editing. Independent verification for Risk item 4: asynchronous Sketcher/observer/window callbacks must not double-apply, discard unrelated edits, or retain orphan sessions.
