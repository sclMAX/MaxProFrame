Objective: portable folder libraries containing editable, autonomous section sketches; branch: `feat/portable-custom-libraries` (base `7eb2f38`, verified default `main`).
Delivery: `auto-chain` / `feature-branch-chain`, local reviewable work-unit commits only; no push/PR/merge authorization. Tests: isolated FreeCAD GUI offscreen, public APIs, distinct RED/GREEN logs, per-unit differential controls.
