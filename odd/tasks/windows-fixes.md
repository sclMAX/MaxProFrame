# Windows portability fixes

Make the native suite pass on the informative Windows CI job (FreeCAD 1.1.4 portable): fix the two product bugs Windows exposes and the tests that assume Linux.
Worktree `.git/gentle-worktrees/windows-fixes`, branch `fix/windows-portability` from origin/main a7eab17. Windows evidence: CI run 41309603409 reports in `<main checkout>/.git/win-fails/w1..w3` (tests.log per shard). Local native runner: `/usr/bin/python3 ci/run_tests.py --freecad-bin <main checkout>/.git/ci-policy-runtime/squashfs-root/AppRun --reports <dir>`.

## Specs

- S1. "vamos con el 1" — item 1 of the follow-ups: fix the 16 Windows failures (13 tests) of run 41309603409 so the Windows job can later become blocking. No skips unless a failure is proven to be an environment limit, and then the skip names the reason.
- S2. Portable library manifests never store OS separators: a captured section's `asset_path` is written as `sections/<file>` on every OS (today `freecad/maxproframe/section_capture.py:352` uses `os.path.join`, giving `sections\<file>` on Windows, which `library_archive.py:21` refuses to export and Linux/macOS cannot resolve via `section_library.py:57,79`). Manifests already written on Windows with `\` in `asset_path` keep working on every OS: they resolve, export to ZIP, duplicate, and when the library is saved its manifest is written with `/`.
- S3. Custom profile card thumbnails build the section face without the document fallback on Windows: `custom_profile_cards.py:251` must not reopen an open `NamedTemporaryFile` by name (load from memory or a closed temp file that is always deleted).
- S4. Tests stop assuming Linux: elided-text tests accept the ellipsis the active font produces and derive widths from font metrics (A); expected paths in `test_t5_boundary` / `test_portable_library_profile_instantiation` use the manifest form and normalized real paths (B'); `test_compile_translations` tolerates case-insensitive file systems (C); text files are read with `encoding="utf-8"` (D). Linux behavior of the tests is unchanged.
